# KDE Store listing — v22.0.0

## Product description

Monitor AI usage, quotas and costs from your KDE Plasma 6 panel.

AI Usage Monitor brings your providers and coding tools into one overview. See which source needs attention, follow spending and budgets, and review your usage history. Provider-reported values and local estimates are clearly labelled; missing data stays unavailable.

### What you can do

- **Follow usage and quotas** across API providers and coding tools.
- **Control budgets** with local policies, spending trends and notifications.
- **Understand source health** with freshness, connection status and recovery actions.
- **Review and export history** with JSON and CSV exports.

### New in V22

Safer settings import with Apply and Cancel, more reliable local activity monitoring, clearer history maintenance, and delivery status with retries for budget alerts. Guided setup also recovers interrupted checks.

### Supported sources

**Coding tools:** Codex CLI, Claude Code, GitHub Copilot, Cursor, Windsurf, JetBrains AI and Google Antigravity.

**API providers:** OpenAI, Anthropic, Google Gemini, OpenRouter, DeepSeek, Mistral and more. See the [user guide](https://github.com/loofiboss-bit/plasma-ai-usage-monitor/wiki) for the full source list and available data.

### Installation

**The Store download contains the Plasma frontend. It requires the matching V22 native plugin from Fedora COPR or a source build.**

On Fedora:

```sh
sudo dnf copr enable loofitheboss/plasma-ai-usage-monitor
sudo dnf install plasma-ai-usage-monitor
```

Log out and back in after the first installation, then add **AI Usage Monitor** to your panel. For other distributions, follow the [source installation guide](https://github.com/loofiboss-bit/plasma-ai-usage-monitor#installation).

### Privacy

Credentials are stored in KWallet. Usage history and budget policies stay in a local database. Optional Slack and Discord alerts send only limited summaries to your configured webhook.
