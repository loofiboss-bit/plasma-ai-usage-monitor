# AI Usage Monitor for KDE Plasma 6
### The Unified AI Control Center for API Costs, Quotas & Coding Sessions

**AI Usage Monitor** seamlessly integrates your AI workflow directly into your KDE Plasma desktop. Monitor live API quotas, follow token spend, audit local coding activity, and enforce personal spending limits — all in a unified, privacy-first interface. Provider-reported values and local estimates stay clearly labelled; missing data remains unavailable.

---

### 🌟 Key Highlights

- **⚡ Multi-Window Quota Tracking**: Follow up to three active quota windows per tool (rolling windows, weekly quotas, Antigravity family allowances) with real-time countdowns and local clock reset times (`resetAt`).
- **📊 Cross-Tool Session Analytics**: Deep-dive into local coding sessions across Codex CLI and Claude Code. Compare token distribution, cache hit efficiency (`cacheHitPercent`), and project activity over 7/30 days or custom date ranges.
- **🛡️ 100% Local & Privacy-First**: Zero external telemetry. Sensitive credentials stay in your native **KWallet**, history resides in a local SQLite database, and session telemetry never tracks your prompts or code.
- **🔔 Actionable Desktop Alerts**: Opt-in to quota reset notifications (*Quota Reset Ready*), smart rate-limit warnings with exact clock reset times, and configurable noise-reduction filters (e.g. *Favorites only*).
- **🎨 Native Plasma 6 Polish**: Designed specifically for KDE Plasma 6 with mouse-wheel favorite cycling right on the panel, keyboard shortcuts (`Alt+1..3`, `Escape`), and high-DPI responsive layouts.

---

### 🚀 What's New in V26.0.0 — AI Control Center & Smart Usage Experience

V26 upgrades the monitor into a unified AI Control Center while preserving the boundaries between provider billing, subscription quotas, and locally reported coding activity.

- **Unified Quota Overview & Multi-Window Strips**: Displays up to three active quota windows per source (e.g. Codex CLI 5h rolling + weekly, Claude Code 5h + weekly, Google Antigravity model-family windows) with remaining percentage, relative countdown, and local clock reset times.
- **Overview Control Strip & Fast Navigation**: Filter quickly by *All*, *Favorites*, or *Needs attention*. Use keyboard shortcuts (`Alt+1..3` for top-level tabs, `Escape` to return or clear search) and direct drill-down links.
- **Cross-Tool Session Analytics**: In Insights → Coding sessions, compare *All tools* (Codex CLI vs Claude Code) or single tools across 7/30 completed local calendar days or custom ranges. Includes *By tool* breakdowns, token share percentages (`sharePercent`), and cache-read efficiency (`cacheHitPercent`).
- **Actionable Notifications**: Adds opt-in notifications when quota windows reset (*Quota Reset Ready*), relative + clock reset times in warnings, direct *Open Source Details* notification actions, and optional *Favorites only for warnings* noise reduction.
- **Plasma Panel Favorite Cycling & Performance**: Mouse-wheel scrolling over the panel cycles through starred favorites. Performance optimizations eliminate hot-path regexes and improve query and scaling speed.

### 🏁 Getting Started

1. Install the complete Fedora package below, or build both parts from source.
2. Log out and back in, then right-click your panel, select **Add Widgets...**, and add **AI Usage Monitor**.
3. Complete **Guided first success** for one tool or provider. For local Codex and Claude Code tokens, enable that tool's session data in **Settings → History** and choose **Apply**, then open **History → Sessions**.

*An API provider is optional for local-tool monitoring. Source labels distinguish live quotas, reported usage, local estimates, and connection checks.*

### 📦 Installation

> **Notice:** The Store download contains the Plasma frontend. It requires the matching V26.0.0 native plugin from Fedora COPR or a source build.

#### Fedora (Recommended — Single Step via COPR)
On Fedora, the COPR package includes both parts; no extra Store download is needed:

```sh
sudo dnf copr enable loofitheboss/plasma-ai-usage-monitor
sudo dnf install plasma-ai-usage-monitor
```

Check the [COPR project](https://copr.fedorainfracloud.org/coprs/loofitheboss/plasma-ai-usage-monitor/) for builds for your Fedora release. Fedora 44 and Fedora 45 are the release baselines.

Update with `sudo dnf upgrade --refresh plasma-ai-usage-monitor`, then log out and back in. Keep frontend and plugin versions matched. For other Plasma 6 distributions, follow the [source installation guide](https://github.com/loofiboss-bit/plasma-ai-usage-monitor/blob/main/docs/user-guide/installation.md#guided-source-install).

---

### 🔒 Privacy & Architecture

Credentials are stored in **KWallet**. Usage history, project aliases, and budget policies stay locally. The widget does not send telemetry or use a hosted backend. Optional webhooks send limited summaries to destinations you configure. Local session history stores allowlisted metadata and usage fields, not prompts, replies, or conversation titles. Session tokens are not converted into subscription percentages, billed costs, or productivity scores.
