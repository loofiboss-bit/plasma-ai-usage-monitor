## Product description

# AI Usage Monitor for KDE Plasma 6

AI Usage Monitor is a desktop widget for KDE Plasma 6 that tracks API consumption, tool quotas, and local coding sessions across development tools and model providers.

The widget distinguishes between provider billing metrics, subscription rate limits, and locally parsed coding activity. Provider values reflect official API reports; missing data remains explicitly unavailable rather than guessed.

---

### Key Capabilities

- **Quota Tracking & Rolling Windows**: Displays up to three concurrent quota windows per service (such as rolling 5-hour and weekly reset cycles) with remaining percentages, countdowns, and local reset timestamps.
- **Cross-Tool Session Analytics**: Compares local coding activity across supported tools (Codex CLI, Claude Code) over 7-day, 30-day, or custom date ranges, reporting token usage, tool share percentages, and cache read efficiency.
- **Spending & Budget Controls**: Enforces optional local spending limits and thresholds with desktop alerts, avoiding unexpected API charges.
- **Native Plasma 6 Integration**: Supports mouse-wheel scrolling directly over the panel applet to cycle through starred sources, keyboard navigation (`Alt+1..3`, `Escape`), and high-DPI displays.
- **Fully Local Architecture**: API credentials reside in KWallet; history and preferences are stored in a local SQLite database without remote telemetry or telemetry servers.

---

### What's New in Version 26.0.0

- **Multi-Window Quota Strips**: Monitors multi-tier quota models directly in the overview strip, displaying active windows with relative timers and exact clock reset times.
- **Control Strip Navigation**: Adds quick-filter views (*All*, *Favorites*, *Needs attention*) and keyboard shortcuts for immediate drill-down.
- **Cross-Tool Coding Comparison**: Evaluates multi-tool activity over calendar days with token share (`sharePercent`) and prompt cache efficiency (`cacheHitPercent`).
- **Actionable Notifications**: Adds opt-in notifications when quota windows reset (*Quota Reset Ready*), actionable buttons to open source details directly from alerts, and a setting to limit warning popups to favorite sources.
- **Performance Improvements**: Removes hot-path regular expressions during data refreshes and speeds up panel scrolling interactions.
- **Fedora 44 & 45 Packaging**: Ships verified packages for current Fedora releases.

---

### Supported Services

- **Coding Tools**: Codex CLI, Claude Code, GitHub Copilot, Cursor, Windsurf, JetBrains AI, Google Antigravity.
- **API Providers**: OpenAI, Anthropic, Google Gemini, OpenRouter, DeepSeek, Mistral, and compatible OpenAI-format endpoints.

*Note: An API key is only required if monitoring remote provider APIs; local coding tools work without API keys.*

### Installation

The KDE Store archive contains only the QML desktop frontend. Running the widget requires the companion native C++ plugin (`plasma-ai-usage-monitor`) compiled for your system.

#### Fedora (Recommended)
The official Fedora COPR repository packages both the QML frontend and the compiled C++ plugin together:

```sh
sudo dnf copr enable loofitheboss/plasma-ai-usage-monitor
sudo dnf install plasma-ai-usage-monitor
```

After installation or update, log out of your desktop session and back in. Then right-click your panel, choose **Add Widgets...**, and add **AI Usage Monitor**.

To update existing installations:
```sh
sudo dnf upgrade --refresh plasma-ai-usage-monitor
```

#### Other Distributions / Build from Source
To compile the native plugin and install the frontend manually on other distributions, follow the [source build instructions](https://github.com/loofiboss-bit/plasma-ai-usage-monitor/blob/main/docs/user-guide/installation.md#guided-source-install).

---

### Privacy & Storage Model

- **Credentials**: Stored exclusively in the system keyring via KWallet.
- **Local Database**: Usage history, custom project aliases, and budget policies stay on your local drive in `~/.local/share/plasma-ai-usage-monitor/`.
- **Session Privacy**: Local session parsers read allowlisted token numbers and timing metadata only. Prompts, completions, file paths, and conversation titles are neither recorded nor stored.
- **No Hosted Backends**: The plasmoid communicates directly and only with the specific provider APIs you configure. It does not send analytics, telemetry, or diagnostic beacons to any intermediary server.
