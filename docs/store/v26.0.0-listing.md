# AI Usage Monitor 26.0.0 — AI Control Center & Smart Usage Experience

AI Usage Monitor is an original GPLv3-licensed KDE Plasma 6 monitoring applet for provider API consumption, subscription rate limits, and local coding-session activity. It integrates OpenAI, Anthropic, Google Gemini, OpenRouter, DeepSeek, Mistral, and local tools (Codex CLI, Claude Code, GitHub Copilot, Cursor, Windsurf, JetBrains AI, Google Antigravity) into a unified overview while keeping provider-reported billing, subscription quotas, and local estimates strictly separated. Missing provider data remains explicitly unavailable rather than guessed.

Version 26.0.0 upgrades the monitor into an AI Control Center with multi-window quota strips (up to 3 concurrent windows with relative countdowns and local clock `resetAt` times), an overview control strip with quick filters (*All*, *Favorites*, *Needs attention*) and `Alt+1..3`/`Escape` navigation, cross-tool coding-session comparisons (*All tools* with `sharePercent` and `cacheHitPercent` efficiency over 7/30 completed local days), actionable quota reset notifications, and mouse-wheel panel favorite cycling.

The KDE Store archive contains the Plasma 6 QML frontend only. Running the widget requires the matching compiled C++ native plugin (`plasma-ai-usage-monitor-26.0.0`). The official Fedora COPR package provides both parts together:

```sh
sudo dnf copr enable loofitheboss/plasma-ai-usage-monitor
sudo dnf install plasma-ai-usage-monitor
```

Log out and back into Plasma after installation, then add **AI Usage Monitor** from the widget explorer. Existing installations update via `sudo dnf upgrade --refresh plasma-ai-usage-monitor`. For non-Fedora distributions, compile the native plugin from the source repository.

Credentials reside exclusively in KWallet. History, project aliases, and budget policies stay in a local SQLite database (`~/.local/share/plasma-ai-usage-monitor/`). Local session monitoring reads allowlisted token usage and timing metadata only; it never logs prompts, replies, file contents, or conversation titles. The plasmoid communicates directly with configured endpoints without third-party telemetry or hosted backends.

## Changelog text

- Unified Quota Overview with multi-window quota strips (up to 3 windows with countdowns and local clock reset times).
- Overview Control Strip with quick filter pills (*All*, *Favorites*, *Needs attention*) and fast keyboard shortcuts (`Alt+1..3`, `Escape`).
