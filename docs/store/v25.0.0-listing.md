# KDE Store listing — v25.0.0

## Product description

AI Usage Monitor for KDE Plasma 6 — API costs, tool quotas, and local coding-session history.

AI Usage Monitor brings API providers and local coding tools into one overview. Provider-reported values and local estimates stay clearly labelled; missing data remains unavailable.

### New in V25.0.0 — Searchable Session History

Search local project choices and reported models across Codex and Claude Code session history. Keep active filters and navigation context across summaries, daily totals, analysis breakdowns, and session details.

Manual JSON and CSV exports share active filters and stream to private atomic files. Deleted Codex totals stay deleted across rescans. Imports safely skip oversized log records, and Overview/Sources add a one-action filter and search reset.

### Get started

1. Install the complete Fedora package below, or build both parts from source.
2. Log out and back in, then open **Add Widgets** and search for **AI Usage Monitor**.
3. Complete **Guided first success** for one tool or provider. For local Codex
   and Claude Code tokens, enable that tool's session data in **Settings → History**
   and choose **Apply**, then open **History → Sessions**.

An API provider is optional for local-tool monitoring. Source labels distinguish
live quotas, reported usage, local estimates, and connection checks.

### Existing features

Follow API usage and quotas, review source freshness and recovery actions, manage local spending budgets and notifications, and export provider history. Spend totals preserve compatible currencies, periods, quality, and actual-versus-estimated meaning.

Local session history is separately enabled for Codex CLI and Claude Code. It stores allowlisted metadata and usage fields, not prompts, replies, or conversation titles. Session tokens are not converted into subscription percentages, billed costs, or productivity scores.

### Supported sources

**Coding tools:** Codex CLI, Claude Code, GitHub Copilot, Cursor, Windsurf, JetBrains AI, and Google Antigravity.

**API providers:** OpenAI, Anthropic, Google Gemini, OpenRouter, DeepSeek, Mistral, and more. See the [user guide](https://github.com/loofiboss-bit/plasma-ai-usage-monitor/wiki) for the full source list and available data.

### Installation

**The Store download contains the Plasma frontend. It requires the matching V25.0.0 native plugin from Fedora COPR or a source build.**

On Fedora, the COPR package includes both parts; no extra Store download is needed:

```sh
sudo dnf copr enable loofitheboss/plasma-ai-usage-monitor
sudo dnf install plasma-ai-usage-monitor
```

Check the [COPR project](https://copr.fedorainfracloud.org/coprs/loofitheboss/plasma-ai-usage-monitor/) for builds for your Fedora release. Fedora 44 is the release baseline.

Update with `sudo dnf upgrade --refresh plasma-ai-usage-monitor`, then log out and back in. Keep frontend and plugin versions matched. For other Plasma 6 distributions, follow the [source installation guide](https://github.com/loofiboss-bit/plasma-ai-usage-monitor/blob/main/docs/user-guide/installation.md#guided-source-install).

### Privacy

Credentials are stored in KWallet. Usage history, project aliases, and budget policies stay locally. The widget does not send telemetry or use a hosted backend. Optional webhooks send limited summaries to destinations you configure.
