# KDE Store listing — v23.0.0

## Product description

Monitor AI usage, quotas, and costs from your KDE Plasma 6 panel.

AI Usage Monitor brings API providers and local coding tools into one overview. See which sources need attention, follow spend and budgets, and review usage history. Provider-reported values and local estimates are labelled separately; missing data stays unavailable.

### What you can do

- **Follow usage and quotas** across API providers and coding tools.
- **Understand costs** with currency, period, unit, measurement type, and data quality kept visible.
- **Control budgets** with local policies, spending trends, and notifications.
- **Review and export history** with selected-series JSON and CSV exports that omit raw scope identifiers.
- **Understand source health** with freshness, connection status, scheduled refreshes, and recovery actions.

### New in V23

Spend is grouped only when currency, period, and actual-versus-estimated meaning are compatible. Requests, tokens, credits, and balances keep their own units; daily, monthly, current-period, and all-time values are not combined into misleading totals.

Local coding-tool monitors cancel in-flight requests when disabled. Refresh timing follows the actual next run, temporary errors use retry delays, and external automatic checks pause while the network is explicitly offline. Catalog expiry is checked during the session so new local estimates become unavailable when their verified price data expires.

Source selection and the overview are searchable. Prometheus displays its listener status and startup errors, while webhook delivery shows the latest safe result.

### Supported sources

**Coding tools:** Codex CLI, Claude Code, GitHub Copilot, Cursor, Windsurf, JetBrains AI, and Google Antigravity.

**API providers:** OpenAI, Anthropic, Google Gemini, OpenRouter, DeepSeek, Mistral, and more. See the [user guide](https://github.com/loofiboss-bit/plasma-ai-usage-monitor/wiki) for the full source list and available data.

### Installation

**The Store download contains the Plasma frontend. It requires the matching V23 native plugin from Fedora COPR or a source build.**

On Fedora:

```sh
sudo dnf copr enable loofitheboss/plasma-ai-usage-monitor
sudo dnf install plasma-ai-usage-monitor
```

Log out and back in after the first installation, then add **AI Usage Monitor** to your panel. For other distributions, follow the [source installation guide](https://github.com/loofiboss-bit/plasma-ai-usage-monitor#installation).

### Privacy

Credentials are stored in KWallet. Usage history and budget policies stay in a local database. Optional Slack and Discord alerts send only limited summaries to your configured webhook. The widget does not send telemetry or use a hosted backend.

## Changelog text

- Keep spend totals separated by compatible currency, period, actual or estimated meaning, and quality; retain units for non-monetary metrics.
- Cancel pending local-tool syncs when disabled and prevent later fallback requests, history writes, or notifications.
- Enforce verified catalog expiry during the session and refresh installed catalog data without restarting Plasma.
- Schedule source updates from their real completion time, respect retry delays and explicit offline state, and keep manual refresh available.
- Search onboarding and overview sources; show Prometheus listener failures and the latest safe webhook delivery result.
- Export selected history series using the documented schema-v6 field allowlist with raw scope identifiers redacted.

The V23 database keeps existing user history and credentials. The Store frontend requires the matching V23 native plugin from COPR or a source build.
