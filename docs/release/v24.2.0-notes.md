# V24.2.0 — Structured Usage & Sources

- See current status and actions first in Overview, with API services and AI tools grouped under Sources.
- Configure sources through shared staged settings and credentials, then verify their connection and data source before applying advanced overrides.
- Keep Browser Sync in a dedicated section and preserve the pending Apply state when changing sections.
- Use a clearer History layout for usage and coding sessions, with grouped filters and exports and explicit loading, error, and empty states.
- Create named project aliases by selecting a folder and entering a name. Folder paths are not stored, and alias changes preserve session history.
- Open a session from a summary and continue in History with its tool, project, range, page, and selection intact.

The KDE Store widget requires the matching 24.2.0 native plugin from Fedora COPR or a source build.
