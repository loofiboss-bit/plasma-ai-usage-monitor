# v23.0.0 Clearer and More Reliable Daily Use qualification checklist

Status: review candidate on `feat/v23-trustworthy-everyday-use`; not published.
Public release, COPR, KDE Store and wiki steps have not been authorized by this
checklist. Physical narrow-popup, keyboard and screen-reader qualification must
remain explicitly recorded until performed.

## Local qualification

- [x] Version policy surfaces agree on 23.0.0; V22 release history is retained.
- [x] `just check` passes, including generated wiki and development-media checks.
- [x] QML lint passes for all shipped files with no unsuppressed warnings.
- [ ] ASan/UBSan Debug build passes; CTest is 75/76 because the unchanged
  100,000-observation runway-query check measured 834 ms against its 750 ms
  threshold. The same test passed in an earlier run on this source change.
- [x] The dedicated phase-7 performance suite passes; the separate sanitizer
  runway-query timing threshold remains unresolved.
- [ ] Full Debug CTest passes. The 76-test run excluding release-candidate
  media checks passes 76/76. The full run is 76/78 because `release_media`
  and `release_media_source_archive` still identify V22 media as the V23
  release capture. V23 media has not been captured or physically qualified.
- [x] AppStream validation and `rpmlint` pass; the source archive and plasmoid
  build from the candidate source.
- [x] Fedora SRPM and binary RPM are built from the V23 candidate source; the
  installed binary was rebuilt from that source for Fedora 44.
- [x] Candidate Fedora RPM reinstall, package integrity, runtime package
  version, system plasmoid selection, and user-data preservation are verified
  on this host. The user-local V22 package was an exact match for the tracked
  V22 package, archived before removal, and no longer shadows the V23 system
  package.

## Behavior and regression coverage

- [x] Spend aggregation preserves compatible currency, period, semantics and
  quality groups; current and all-time metrics stay source-specific.
- [x] Disabled subscription monitors cancel pending responses and suppress
  later fallback requests and data writes.
- [x] Selected-series JSON and CSV use an explicit schema-v6 field allowlist;
  sentinel scope and internal values are excluded.
- [x] Catalog expiry, catalog refresh, retry scheduling, offline behavior,
  Prometheus bind failures and webhook response classes have automated tests.
- [x] Search, filtering, source capabilities, scaling and accessibility
  contracts pass automated tests.

## Manual qualification

- [ ] Review the installed V23 UI in a narrow popup and at supported scaling
  factors in an ordinary Plasma session.
- [ ] Verify keyboard navigation and focus recovery in setup and settings.
- [ ] Navigate setup and status with a screen reader.
- [ ] Recapture release media against the exact V23 source and fixture tree.

## Pull request

- [ ] Commit the candidate, push the feature branch, and open a PR against
  `main`.
- [ ] Read back the PR identity and initial CI status.

No merge, tag, package publication, or Store update is part of this candidate.

Provider API keys and live provider accounts are optional release evidence and never block publication.

When a separate publication task is authorized, the stable gate requires this
action: Publish `v23.0.0` directly from the verified `main` commit after the
required gates pass. No prerelease or timed soak is required.
