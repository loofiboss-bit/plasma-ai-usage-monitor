# v14.1.2 release notes

v14.1.2 is a daily-truth maintenance release. The panel, popup footer, and
accessibility label now describe verified sources rather than provider
connections. Tool-only setups can report healthy status, while unverified,
unavailable, and connectivity-only states no longer imply usage.

Compact cost, remaining-request, and quota modes consume available source data.
An explicit zero remains visible, unavailable data uses an em dash, and mixed
currencies remain separate.

Analyst now labels the output/input ratio as a neutral relationship. It omits
days without positive input, retains explicit zero output, and no longer assigns
prompt quality, recommendations, trend arrows, or positive/negative colors.
Heatmap hover text distinguishes missing observations from recorded zero
activity.

This update keeps KConfig keys and stored compact-mode values unchanged, keeps
KWallet identities unchanged, and retains SQLite schema version 4. No provider,
distribution, or secret identity is added.
