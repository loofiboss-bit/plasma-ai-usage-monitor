# V25.0.0 publication copy

Prepared text only. These drafts do not establish publication on any surface.
Use the verified final release artifacts and publication checklist when the
release is authorized.

## GitHub

### AI Usage Monitor 25.0.0 — Searchable Session History

Find local Codex and Claude Code sessions by project and reported model. Search
complete project/model choices, keep the active selection visible, and move
between summaries, daily totals, analysis and session details without losing
your filters. Manual JSON/CSV exports use the same selection and stream to
private atomic files.

This release also fixes deleted Codex totals returning after rescans, resumes
past oversized log records, rejects outdated Overview results, and adds clear
search/filter reset actions. Source verification distinguishes reporting,
connectivity, waiting, warnings and failures.

Local collection remains independently opt-in for each tool. Prompts, replies,
local paths and aliases are excluded from session exports. Existing settings,
aliases and retained history remain compatible.

The Fedora COPR package includes both the Plasma frontend and native plugin.
The `.plasmoid` asset contains the frontend only and requires the matching
25.0.0 native plugin. Checksums and build provenance must be read back from the
published release before claiming delivery.

## KDE Store

### Version 25.0.0 — Searchable Session History

Search local projects and reported models across Codex and Claude Code session
history. Keep filters and navigation context, export matching JSON/CSV, and see
clear retry and partial-coverage explanations. Includes import reliability,
Overview navigation, source verification and search/filter reset improvements.

**Requires the matching AI Usage Monitor 25.0.0 compiled native plugin. This
Store download contains only the Plasma frontend.** On Fedora, install the
complete COPR package. On other supported Plasma 6 systems, build and install
the matching native plugin before using this frontend.

## COPR

### plasma-ai-usage-monitor 25.0.0

KDE Plasma 6 widget with searchable local session history, exact/unknown model
filters, consistent filtered summaries and private streamed exports. Fixes
Codex history deletion/rebaseline and oversized JSONL import recovery, and
improves source verification and filter recovery.

The RPM includes both the widget and matching native plugin. Fedora 44 is the
release baseline; Fedora 45 is additionally qualified by isolated package
checks. Announce availability for each target only after its public signed
build and repository package have been verified.

## Verification boundary

Automated tests, isolated package lifecycles and synthetic images do not prove
physical Plasma scaling, screen-reader operation, live provider accounts or
public availability. Report those results separately using the qualification
checklist. Publication requires the verified stable tag on the exact `main`
commit, the canonical Release workflow, GitHub assets/checksums/provenance,
signed COPR packages and the public KDE Store version/artifact.
