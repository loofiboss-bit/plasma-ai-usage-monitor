### Changes under qualification

- Preserve clear/rebaseline across empty scans, restarts and older pending flags;
  only matching creation metadata with an explicit timezone can prove a new
  Codex session. Uncertain first snapshots retain partial coverage.
- Skip oversized JSONL records using bounded reads and safe resume cursors,
  including Codex context replay. The existing 100 MiB per-file and 256 MiB
  per-scan limits remain in force.
- Reject session-summary responses from previous Overview instances, explain
  filtered search misses, and add search/filter reset in Overview and Sources.
- Keep the active project visible during chooser search and distinguish pinned
  selection from actual matches.
- Present all verification states explicitly, with success restricted to
  reporting/connectivity and a neutral unknown-state fallback.
