# AI Usage Monitor 17.0.0 — Runway Guardrails

Runway Guardrails adds deterministic, local projections for synchronized quota
and configured monthly budgets while preserving the widget's read-only,
local-first boundary.

## Highlights

- Complete bounded pagination for OpenAI usage, daily cost, and monthly cost
  reports; partial traversals can no longer appear as complete totals.
- Provider-reported OpenAI and Anthropic scope detail without invented
  dimensions or aggregate double counting.
- Deterministic quota runway and monthly budget pacing with explicit samples,
  coverage, evidence, method, UTC period, actual/estimated class, and typed
  unavailable reasons.
- Daily Focus, Source Detail, and Analyst integration without a new primary tab
  or a changed compact-panel default.
- Opt-in warning, critical, and recovery notifications deduplicated across
  refreshes and restarts.
- Aggregate-only Prometheus guardrail state and event timing with no model,
  project, workspace, or API-key labels.
- Transactional SQLite schema-v5 migration with a pre-migration `.v17-backup`,
  separate guardrail transition evidence, export, and retention support.
- Neutral Output / Input Ratio terminology and removal of unused subjective
  Analyst components.

## Compatibility

The package ID, QML URI, notification identity, AppStream identity, KWallet
folder and secret keys, provider/subscription catalogs, existing KConfig keys,
and existing observation history remain compatible. New guardrail settings use
the existing `Budget` KConfig group.

The v4-to-v5 database migration preserves observations and is retryable after
an injected failure. Removing or rolling back the RPM does not delete user
configuration, KWallet entries, or history; an older binary may not understand
the schema-v5 transition table, so preserve the `.v17-backup` when performing a
manual application-level rollback.

## Safety and privacy

Forecast calculations are local and deterministic. The release adds no LLM
inference, hosted backend, currency conversion, provider writes, automatic
model switching, provider, subscription tool, or fourth primary tab.

Forecast notifications remain off by default. Raw scoped identifiers remain
local and are excluded from default webhook and Prometheus payloads.

See the [Runway guardrails guide](../user-guide/runway-guardrails.md) for the
calculation and unavailable-state contract.
