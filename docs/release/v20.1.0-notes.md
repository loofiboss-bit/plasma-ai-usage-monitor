# v20.1.0 Quota Observability & Platform Flexibility

AI Usage Monitor v20.1.0 expands local quota observability, adds network listening and release-checking privacy controls, and delivers platform-aware diagnostics for FreeBSD and generic Linux.

## Highlights

- **Codex Local Auth Sync**: Automatic quota refreshes read five-hour and weekly quota windows directly from the user's existing CLI authentication (`codex login`) without depending on Browser Sync, browser cookies, or Claude circuit breakers.
- **Automatic Release Check Control**: Added an explicit privacy control (`automaticUpdateChecks`, default on) in Settings. Disabling it stops periodic polling and prevents unsolicited requests to the GitHub Releases API.
- **Prometheus Live Quotas & Network Access**: Added an opt-in setting (`prometheusListenAllInterfaces`, default false / loopback only) with in-UI warnings for unauthenticated/unencrypted network exposure. Authenticated live quotas (`ai_usage_tool_quota_percent_remaining`, `ai_usage_tool_quota_reset_timestamp_seconds`) are regenerated dynamically at scrape time to prevent serving stale or expired quota windows. A starter Grafana dashboard is included at `docs/grafana-dashboard.json`.
- **Platform-Aware Diagnostics & Recovery**: Replaced hardcoded Fedora `dnf` instructions on the missing-plugin screen with platform-neutral guidance. Native diagnostics detects distribution type to provide `dnf`/`rpm` commands on Fedora and portable source build instructions on FreeBSD and generic Linux.

## Installation

Fedora users can install via COPR (`sudo dnf copr enable loofitheboss/plasma-ai-usage-monitor && sudo dnf install plasma-ai-usage-monitor`). Source builds are supported across Linux and FreeBSD. The KDE Store plasmoid is frontend-only and requires a matching v20.1.0 compiled native plugin.
