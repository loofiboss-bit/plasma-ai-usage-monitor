# v20.1.1 Codex Local-Auth Recovery

AI Usage Monitor v20.1.1 is a focused patch release for Codex CLI quota
synchronization.

## Fixed

- Automatic local-auth sync now fingerprints a usable Codex `auth.json`
  snapshot and clears the per-process retry latch when credentials rotate.
- Missing, malformed, or incomplete auth snapshots do not masquerade as a
  credential change.
- Credential changes observed during an in-flight request are retried only
  after that request finishes.
- Browser Sync remains an explicit fallback path and keeps its existing gate.

The release does not add a hosted backend, telemetry, inference requests, or
new providers. Credentials remain local and are never logged; only a SHA-256
fingerprint is retained in process memory.

The KDE Store package remains frontend-only and requires the matching
v20.1.1 compiled plugin from COPR or a source build.
