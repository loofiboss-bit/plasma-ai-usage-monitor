# v10.0.0 Accuracy Release Checklist

## Scope

- Ship the Accuracy release focused on correctness, data-source honesty, onboarding, diagnostics, and release hardening.
- Keep the widget desktop-native and local-first.
- Do not add new providers, backend services, PostgreSQL, web dashboards, runtime pricing scraping, or team/account systems.

## Required Gates

- [ ] `just clean`
- [ ] `just build-debug`
- [ ] `just test`
- [ ] `just check`
- [ ] `just release-check`
- [ ] `just fedora44-check`

## Focus Checks

- [ ] OpenAI daily and monthly Costs API object `amount.value` responses parse without cents conversion.
- [ ] Legacy numeric OpenAI cost fixtures still parse as cents-only mock data.
- [ ] One hundred OpenAI-compatible probe refreshes leave actual usage, spend, budgets, history spend, and displayed request counts unchanged.
- [ ] Provider cards, history exports, Prometheus metrics, and Analyst summaries carry `cost_source`, `usage_source`, `currency`, and `data_quality`.
- [ ] `package/contents/config/main.xml` provider model defaults all exist in `providers-v3.json`.
- [ ] Runtime Copilot, Bedrock, Slack, and Discord secrets load after KWallet opens or delayed key storage becomes visible.
- [ ] Subscription plan and custom-limit changes apply without a Plasma reload.
- [ ] Dashboard and compact cost labels do not silently mix API spend, fixed subscription fees, and estimated burn.
- [ ] Diagnostics support-report copy includes wallet state, Copilot token state, catalog state, Browser Sync readiness, insecure URLs, install state, and alert thresholds.
- [ ] Provider and subscription catalogs show `release: 10.0.0`, `catalogVersion: 2026.05.12`, and `lastReviewed: 2026-05-12`.

## Known Catalog Uncertainty

- [ ] Release notes list remaining provider manual-review entries: Anthropic, Google, Mistral, DeepSeek, Groq, xAI, Ollama Cloud, OpenRouter, Together AI, Cohere, Google Veo, and AWS Bedrock.
- [ ] Release notes list remaining subscription uncertainty: Windsurf manual review and subscription source-conflict visibility.
