# V26.0.0 — AI Control Center & Smart Usage Experience

V26 upgrades the monitor into a unified AI Control Center while preserving the
boundaries between provider billing, subscription quotas and locally reported
coding activity.

## Unified Quota Overview, Daily Focus and favorites

Use the star action on a source card or source details to keep the same favorites
in Overview and the panel. Overview includes a Control Strip with quick filter
pills (*All*, *Favorites*, *Needs attention*) and search, plus multi-window
quota strips on source cards showing up to three active windows (such as 5h
rolling and weekly windows for Codex and Claude Code, or model-family windows
for Google Antigravity) with remaining percentages, relative reset countdowns
and local clock reset times. Global warnings remain visible even when another
source or filter is selected. Keyboard shortcuts (`Alt+1..3`, `Escape`) speed up
popup navigation.

## Session Intelligence and Cross-Tool Comparison

In Insights, choose Coding sessions. Compare *All tools* (Codex CLI vs. Claude
Code) or a single tool across the last seven or 30 completed local calendar days
(or a custom completed interval) against the preceding period. Breakdowns cover
*By project*, *By model*, *By day* and *By tool*, including token share
percentages (`sharePercent`) and cache-read efficiency (`cacheHitPercent`).
Clicking a project, model, day or tool drills directly into the filtered view.
Category coverage, missing values and retention limitations are shown with the
results. Cache values are already part of input.

## Actionable Notifications

Notifications now include *Quota Reset Ready* (`quotaReset`) when a previously
constrained quota window resets, relative + local clock reset times in quota
warnings, clickable *Open Source Details* actions that open the popup directly on
the affected source, and an optional *Favorites only for warnings* setting that
reduces non-critical warning noise while never suppressing critical alerts.

## Plasma panel and Performance

Settings → General lets you choose the panel metric and automatic, all-source or
single-source scope. Automatic scope uses favorites when configured, and
scrolling the mouse wheel over the panel cycles through starred favorites.
Hot-path parsing, SQL query preparation, currency/cost scaling and overview
filtering have been optimized (consolidating PRs #93–#105).

## Compatibility, Fedora 44/45 release readiness and qualification

SQLite v9, config schema v3 and session export v1 are unchanged. Existing panel
settings and legacy aliases continue to work. New config values are optional.
No project paths, prompts or conversation text are added to history or exports.
Release workflows and COPR submission scripts build and verify both Fedora 44
and Fedora 45 packages (`fedora-44-x86_64` and `fedora-45-x86_64`, alongside
`fedora-43-x86_64` on COPR).
See the [qualification checklist](v26.0.0-checklist.md) for actual verification.
