# Plasma AI Usage Monitor 19.0.1 — Catalog Drift Reliability

Version 19.0.1 is a focused patch release following Verified Cost
Intelligence v19.0.0.

## Fixes

- Catalog drift reports now retain every review item while distinguishing
  expected manual-review states from actionable drift.
- The scheduled workflow fails only for actionable drift or catalog errors;
  lifecycle replacements, deliberately unavailable pricing, and transient
  source timeouts remain visible without reopening the maintainer issue.
- Catalog v7 source evidence was refreshed on 2026-08-17.
- Gemini 3.5 Flash, Gemini 3.5 Flash-Lite, and Gemini 3.6 Flash carry current
  official pricing metadata. Retired Gemini 2.0 Flash points to Gemini 3.6
  Flash, and the native Google backend no longer defaults to the retired model.
- Regression tests cover the strict review modes, stale-source detection, and
  transient network classification.

## Distribution boundary

The KDE Store package remains the Plasma frontend only. Fedora users need the
matching native plugin from the 19.0.1 COPR build or a source build. Runtime
provider scraping and automatic price activation remain disabled.
