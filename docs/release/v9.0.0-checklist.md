# v9.0.0 Confidence Release Checklist

## Scope

- Ship the setup, diagnostics, catalog trust, config portability, and validation hardening release.
- Keep the widget desktop-native and local-first.
- Do not add new providers, backend services, web dashboards, or account systems.

## Required Gates

- [ ] `just check`
- [ ] `just test`
- [ ] `just release-check`
- [ ] `just fedora44-check`

## Focus Checks

- [ ] First-run activation uses the inline onboarding path; `package/contents/ui/SetupWizard.qml` is not shipped.
- [ ] `scripts/check_config_portability.py` covers every non-secret key in `package/contents/config/main.xml`.
- [ ] Provider and subscription catalog review/conflict flags include user-visible reasons.
- [ ] Diagnostics shows catalog review items, KWallet state, Browser Sync readiness, local tool state, current version, and loaded plugin path.
- [ ] AppStream, RPM spec, README, roadmap, changelog, package metadata, and CMake all agree on `9.0.0`.

## Manual Release Follow-Through

- [ ] Create source tarball and plasmoid artifacts.
- [ ] Publish GitHub release `v9.0.0`.
- [ ] Verify COPR picked up the `main` release commit.
- [ ] Update KDE Store using the manual checklist if direct upload is blocked.
