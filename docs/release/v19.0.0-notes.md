# Plasma AI Usage Monitor 19.0.0 — Verified Cost Intelligence

Version 19.0.0 makes provider pricing a reviewed, local, explainable input to
the monitor. It keeps actual usage, estimated cost and unavailable data
separate all the way through the UI, SQLite history and exports.

## Highlights

- Catalog v7 adds explicit model IDs, lifecycle and replacement metadata,
  source review provenance, hard expiry and verification state.
- Cost Engine v2 uses fixed-point arithmetic and exact minor-unit rounding for
  token, generation, video-second, request and additive-fee pricing.
- Estimates understand context tiers, modality, service tier, route, region,
  cache reads, cache writes, batch discounts and free allowances.
- Source Detail explains each estimate, records price-change notices and offers
  a local Cost Lab for bounded what-if comparisons. It never executes a paid
  provider request.
- Signed Catalog v7 feeds use Ed25519 verification, SHA-256 binding, expiry,
  minimum-version checks, monotonic sequence protection and atomic activation.
- Estimated cost provenance survives snapshots, provider metrics, CSV and JSON
  exports. Missing currency is not silently converted to USD.
- Retired models are visible with replacements, while unknown or unavailable
  pricing remains unavailable.

Provider keys and live provider accounts are not required for the deterministic
release tests. Runtime scraping and automatic provider-side model switching
remain disabled.
