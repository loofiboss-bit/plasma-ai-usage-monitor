# v16.0.0 Phase 2 Daily Focus and Source Detail Report

- Date: 2026-07-26
- Branch: `main`
- Stable version: `15.0.0`
- Target version: `16.0.0`

Phase 2 shortens the daily control loop without changing release metadata,
provider behavior, KConfig, KWallet, or SQLite schema v4.

## Navigation and Daily Focus

The popup uses `Kirigami.NavigationTabBar` for Overview, History, and Analyst.
Refresh, guided setup, and Settings are in a separately named keyboard-accessible
toolbar.

Overview replaces the duplicated status, attention, quota/reset, and spend cards
with one Daily Focus. It exposes at most one concrete primary action and keeps
live quota, live reset, actual spend, local estimates, and fixed fees as separate
facts. Source rows follow one deterministic order:

1. sources needing attention;
2. provider-reported actual data;
3. local estimates or balances;
4. connectivity-only checks;
5. unavailable sources.

## Source Detail

`SourceDetailModel` is a registered QML model over the shared
`DailyStateModel`. It exposes:

- source status, freshness, and a concrete source-specific action;
- typed metrics with availability, unit, currency, semantic, scope, window,
  provenance, and quality roles;
- normalized quota windows;
- available/actual/estimated coverage counts;
- a bounded compatible seven-day History request through the existing
  asynchronous schema-v4 database boundary.

Source Detail links to source Settings and prefiltered History. Its History
identity uses each catalog provider's `dbName` or subscription tool's `name`.
Returning to Overview restores keyboard focus to the source row that opened the
detail workflow.

## Truth and compatibility

- Unavailable metric values remain invalid; available numeric zero remains
  available.
- Provider-reported and synchronized quota stays distinct from configured or
  estimated limits.
- Actual spend, estimates, balances, fixed fees, and mixed currencies are not
  combined.
- Package ID, native QML URI, KConfig/export schema, KWallet identifiers,
  SQLite schema v4, notifyrc, and release surfaces are unchanged.
- Stable `VERSION` remains `15.0.0`; no public release action is part of Phase 2.
