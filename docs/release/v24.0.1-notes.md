# Plasma AI Usage Monitor 24.0.1

V24.0.1 fixes overlapping content in Source Detail when local coding-session
history is enabled. The session panel now uses its natural content height, so
the following Runway section remains below it in the scrollable view.

This hotfix does not change session collection, stored data, or configuration.
The KDE Store package remains frontend-only and requires the matching 24.0.1
native plugin from Fedora COPR or a source build.
