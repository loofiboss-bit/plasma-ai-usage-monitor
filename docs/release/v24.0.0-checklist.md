## Implemented and verified

- [x] SQLite v8→v9 session tables migrate transactionally. The schema tests
  inject a migration failure, verify retry, and check a complete, readable
  backup after a WAL-backed fixture. Budget rows survive migration and v9 is
  accepted by the budget-delivery schema.
- [x] Sessions, usage events, file checkpoints, project aliases, and observed
  quota records have separate tables. Collection is opt-in per tool, imports
  run asynchronously, checkpoints and events commit together, and a local
  lock serializes imports across processes.
- [x] Codex cumulative snapshots deduplicate unchanged totals, compute category
  deltas, and flag counter resets and uncertain fork/agent lineage.
- [x] Claude messages use anonymous message identities. Incremental import
  updates a partial message when later usage arrives; conflicting values are
  excluded and reported as partial.
- [x] Missing token fields stay nullable; cache counts are included in reported
  input while remaining available as separate cache-read/write values.
- [x] The shared asynchronous model provides filtered session lists, details,
  daily totals, and model/project summaries. JSON and CSV schema-v1 exports are
  asynchronous, use export-specific anonymous IDs, and exclude aliases, paths,
  and raw session/project IDs.
- [x] Synthetic fixtures check prompt, reply, path, raw identity, and alias
  sentinels at parser/export boundaries. Existing history and provider export
  schemas remain unchanged.
- [x] Overview, Source Detail, History, Analyst, and Settings are covered by
  QML checks and deterministic synthetic screenshots. Guide, changelog,
  roadmap, and generated wiki are updated.
- [x] Debug CTest: 81/81. The 100,000-event query/performance regression passes.
- [x] `just check`, QML lint/accessibility checks, `just phase7-check`, and
  `just release-check` pass. Fedora 44 RPM build and the V23→V24, rollback,
  re-upgrade, remove, clean-install, and reinstall lifecycle pass in isolated
  containers with user data preserved. The host remains on V23.
- [x] ASan/UBSan CTest excluding the unrelated `runwayquery` timing gate:
  80/80 pass, including the V24 session tests.

## PR review corrections (2026-10-12)

The candidate now resolves Codex models from session/turn context and accepts
unknown models. Any file write failure rolls back events, counters, and
checkpoints together. Enabled collectors poll every minute with one active
worker, and visible session panels refresh after import. Claude conflicts
have a durable anonymous tombstone removed only by shared session deletion.
All period queries select usage events by timestamp, including sessions that
continue past the selected interval.

Regression coverage includes realistic model-free token records, restored turn
context on incremental import, injected event/counter/checkpoint failures and
retry, periodic discovery and disable, conflict replay after restart and clear,
and consistent list/summary/daily/model/project/JSON/CSV period selection.
The QML regression covers refresh after import, reopening a hidden panel, and
rejection of a stale reply. Focused Debug checks pass (4/4 suites) and the
session parser/model/schema checks pass under ASan/UBSan (3/3 suites).
The RPM lifecycle evidence above predates these review corrections; it has not
been repeated against a newly rebuilt RPM.
