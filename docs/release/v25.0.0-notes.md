# V25.0.0 — Searchable Session History

AI Usage Monitor brings provider usage, coding-tool quotas, and optional local
session history to your KDE Plasma 6 panel. V25 makes it easier to find a
project, reported model, or day and export exactly the usage you selected.

## Install or upgrade

On Fedora, install both the widget and native plugin from
[COPR](https://copr.fedorainfracloud.org/coprs/loofitheboss/plasma-ai-usage-monitor/):

```sh
sudo dnf copr enable loofitheboss/plasma-ai-usage-monitor
sudo dnf install plasma-ai-usage-monitor
```

Existing users can run `sudo dnf upgrade --refresh plasma-ai-usage-monitor`.
Log out and back in, add **AI Usage Monitor** through **Add Widgets**, and
check matching frontend/plugin versions in **Settings → Diagnostics**.

The [KDE Store download](https://store.kde.org/p/2353976) and GitHub `.plasmoid`
asset contain the frontend only and require the matching **25.0.0 native
plugin**. Fedora COPR already supplies both. Other Plasma 6 systems can use
the [source installation guide](https://github.com/loofiboss-bit/plasma-ai-usage-monitor/blob/main/docs/user-guide/installation.md#guided-source-install).

## Try searchable session history

Enable **Codex session data** or **Claude Code session data** in **Settings →
History** and choose **Apply**. Once the scan completes, open **History →
Sessions**, choose your tool and period, then select a project or model. No API
key is required for local session history. Collection is independently opt-in
for each tool and initially covers up to 30 days within retention.

The [user guide](https://github.com/loofiboss-bit/plasma-ai-usage-monitor/wiki)
explains setup, data quality, budgets, exports, and troubleshooting.

## What changed

Search local project aliases and anonymous project labels, filter by an exact
reported model or Unknown model, and open filtered sessions from analysis rows.
Summaries, daily totals, details and manual JSON/CSV exports share the selected
filters. Multi-model sessions contribute only matching events.

Model search covers the complete chooser without changing the active filter
until selection. The selected model remains visible across searches and empty
project/period selections. Changing tools clears session filters; changing a
project or period retains the model. Navigation restores session/day mode,
searches, page, selected-session focus and scroll. Refreshes clamp obsolete pages
after a completed query.

Manual export freezes its filters and format when the dialog opens and allows
one write per panel. Localized export status survives history refreshes. JSON
and CSV stream to private atomic files while retaining anonymous identities,
JSON null values and the existing export schema. Failed database opens and
early exits release their registered connections.

Overview and Sources offer a single action to clear search and filters.
Overview distinguishes a search miss from a source list with nothing requiring
attention and ignores late session results from previous views. Project
selection stays visible during chooser searches. Source verification explains
waiting, configuration, unavailable and unknown states without implying success.

Deleted Codex totals stay deleted across rescans and restarts. Existing or
uncertain sessions establish a fresh baseline; validated new sessions count
from their first snapshot. Oversized log records are skipped with bounded,
resumable reads so later supported records can still import.

Large imports now skip unchanged completed files and rotate pending files across
scans while giving new files priority. Codex parser context is reused only after
the already-read file prefix is verified. Each tool has a separate live scan
status, last completed result, event count and visible limit or error. A clean
latest scan does not erase a historical coverage gap.

Session history adds inclusive custom local-date ranges within retention and
clickable, keyboard-accessible daily totals. Selecting a day keeps the active
tool, project and model filters; returning restores the daily view's focus and
scroll. Summaries, sessions, daily totals and exports share UTC boundaries
derived from those local days, including daylight-saving transitions. The
current day ends at the time of selection, and first import remains limited to
30 days.

Query failures offer retry instead of appearing as empty history. Coverage
explains incomplete imports, bounded lists show their full matching count, and
pagination follows the matching session summary.

Existing settings, aliases and history remain compatible: SQLite schema v9,
configuration schema v3 and session-export schema v1 are unchanged. Import stays
independently opt-in for Codex and Claude Code. Search text, aliases and paths
remain outside exports. Tokens describe reported usage, not cost, plan use or
productivity. The widget requires the matching 25.0.0 native plugin.

## Compatibility and qualification

Fedora 44 is the release baseline. Check the COPR project for available Fedora
targets. Automated and container package checks do not establish physical
Plasma scaling, accessibility, or live-account qualification.
