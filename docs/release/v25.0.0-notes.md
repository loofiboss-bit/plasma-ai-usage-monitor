# V25.0.0 — Searchable Session History

Local candidate; publication and physical desktop qualification are pending.

Search local project aliases and anonymous project labels, filter by an exact
reported model or Unknown model, and open filtered sessions from analysis rows.
Summaries, daily totals, details and manual JSON/CSV exports share the selected
filters. Multi-model sessions contribute only matching events.

Model search covers the complete chooser without changing the active filter
until selection. The selected model remains visible across searches and empty
project/period selections. Changing tools clears session filters; changing a
project or period retains the model. Navigation restores session/day mode,
searches, page, selected-session focus and scroll. Refreshes clamp obsolete pages
after a completed query.

Manual export freezes its filters and format when the dialog opens and allows
one write per panel. Localized export status survives history refreshes. JSON
and CSV stream to private atomic files while retaining anonymous identities,
JSON null values and the existing export schema. Failed database opens and
early exits release their registered connections.

Query failures offer retry instead of appearing as empty history. Coverage
explains incomplete imports, bounded lists show their full matching count, and
pagination follows the matching session summary.

Existing settings, aliases and history remain compatible: SQLite schema v9,
configuration schema v3 and session-export schema v1 are unchanged. Import stays
independently opt-in for Codex and Claude Code. Search text, aliases and paths
remain outside exports. Tokens describe reported usage, not cost, plan use or
productivity. The widget requires the matching 25.0.0 native plugin.

See the [qualification checklist](v25.0.0-checklist.md) for evidence and limits.
