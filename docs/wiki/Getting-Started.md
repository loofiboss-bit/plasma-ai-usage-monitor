# Getting started

Start with one data source and confirm its source label before adding budgets or integrations.

1. Add **AI Usage Monitor** from Plasma's widget picker.
2. Right-click the widget and open its settings.
3. Choose a panel display under **General**.
4. Enable one provider under **Providers**, or one installed tool under **Subscriptions**.
5. Apply settings and refresh the widget.
6. Open **Diagnostics** and check the version, loaded plugin, KWallet, provider health, and catalogs.

Keys are stored in KWallet. Plasma may ask you to unlock the wallet.

A connected provider can still show unknown usage or spend. This is expected when its API exposes connectivity but no account totals.

Read [Understanding the data](Understanding-the-Data) before configuring budgets.

The full flow is in the [first setup guide](https://github.com/loofiboss-bit/plasma-ai-usage-monitor/blob/main/docs/user-guide/getting-started.md).
